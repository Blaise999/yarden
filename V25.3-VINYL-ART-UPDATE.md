# Yarden ANGEL V25.3 — Vinyl artwork replacement

This update replaces the hand-built sleeve/disc illustration on `/vinyl` with the artist-approved ANGEL sleeve-and-record cutout. The asset is transparent and optimized for the existing charcoal/silver website surface.

## Changes
- `components/landing/AngelExtras.tsx`: replaces the old simulated record/disc markup with one accessible image; removes the misleading `Spin the record` button because the disc and sleeve are a single flattened mockup.
- `app/v25.css`: responsive scale, gentle floating motion, and reduced-motion handling.
- `public/editorial/angel-vinyl-cutout.webp`: trimmed transparent WEBP, 1099×789, approximately 195 KB.

The admin-controlled vinyl interest form, stock/availability messaging, existing site colors, logo, hero, merch, and all payment functions are unchanged. Final pressing and product packaging remain subject to artist approval.

## Deploy
Apply the patch from your existing Git project root without deleting `.git`, then run:

```powershell
npm run check:v25; if ($LASTEXITCODE -eq 0) { npm run build; if ($LASTEXITCODE -eq 0) { git add -A; git commit -m "Yarden V25.3 vinyl product artwork"; if ($LASTEXITCODE -eq 0) { git pull --rebase origin main; if ($LASTEXITCODE -eq 0) { git push origin main } } } }
```

Do not force-push on conflicts. Check `/vinyl` on mobile and desktop after successful Vercel deployment.
