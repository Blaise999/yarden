# Yarden V25.2 — Merch photo and hero typography

Only two visible changes:

- The oversized standalone "YARDEN'S ANGEL" typography panel beside the first merch campaign photo has been removed. The original two-model photo now occupies the campaign presentation on its own, with the moving drop marquee beneath it. Its framing preserves the full photograph instead of cropping the models.
- The homepage's large "ANGEL." title uses a classic high-contrast editorial serif font stack, preserving the existing silver gradient, photograph and layout.

Everything else (payments, vinyl reservations, admin panel, music, mugshot generator and image assets) is unchanged.

## Apply small patch

Extract its contents into the root of your existing Yarden Git repository, overwriting matching files. Then run:

    npm run check:v25
    npm run build

Commit and push only after the build succeeds. The `scripts/check-v25.mjs` test was updated to recognize the pre-existing doubled 13-image auto-scrolling archive and now includes regression assertions for both V25.2 changes.
